How It Works

01 BUILD

Make something software or hardware. Build something YOU care about. Just use a component from broken electronics.

02 DOCUMENT

DevLogs!

03 SUBMIT

Let the Ship Sail! The Shipwrights (Reviewers) will review it.

04 EARN

Get compensated for your time. 20 Leaf Coins per Hour. (20 Leaf Coins are worth $4.00)

05 SPEND

Spend your Leaf Coins on merchandise or products.

What Counts

[ SOFTWARE ]

Build a game, website, app, or distro. (Host it on a DevBoard & use it to control something physical to implement your reforge requirement.)

Tracked via Hackatime = Coding Time + GitHub Time.

[ HARDWARE ]

Build a guided project or your own invention. Must be a physical project. (Hardware projects can also have a software component, but the hardware must be the main focus.)

Tracked via Hackatime & Lapse = Design Time + Build Time + GitHub Time.

Review Process

STAGE 1 — THE BASICS

Do you have everything required? Is it all working? If not, we give feedback and you can resubmit.

STAGE 2 — REPRODUCIBILITY

Was there any part of the project fraudulent? Did you follow the rules? If not, we may have to call the Fire Department and Fraud Squad.

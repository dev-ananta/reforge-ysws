How It Works

01 BUILD

Make something software or hardware. You cannot follow guides/tutorials. Build something YOU care about.

02 DOCUMENT

Write a markdown guide. Keep it simple/beginner-friendly. Someone else needs to replicate it from scratch.

03 SUBMIT

Ship the repo and the guide. We review it.

04 EARN

Get paid for your time. 25 paper/hour.

05 SPEND

SPEND YOUR COINSSS IN SHOP!!

What Counts

[ SOFTWARE ]

Build an app, a game, a website, or a CLI tool.

Tracked via Hackatime = coding time + writing time.

[ HARDWARE ]

Build a dev-board, a quantum computer, or a 3D printer. Must be a physical project.

Tracked via Hackatime & Lapse = design time + build time + writing the guide.

Review Process

STAGE 1 — THE BASICS

Is the format correct? Did you actually write a guide? Other standard checks happen here.

STAGE 2 — REPRODUCIBILITY

Is your guide actually helpful for a beginner? If yes, you earn coins.
